# Project provenance

GARDN was prototyped privately before this public repository was initialised on 17 August 2026.

The product work predates this repository, but the public commits do not claim earlier GitHub activity. Every commit in this public history uses the real time at which that reviewed source slice was published.

## Pre-public product milestones

- **12 August 2026** — the agent workspace was reorganised around a continuous garden lifecycle.
- **13 August 2026** — user-facing provider references were replaced with provider-neutral GARDN language.
- **15 August 2026** — the initial launch scope and staged release gates were prepared.
- **16 August 2026** — mobile first-paint behaviour and the core positioning line were refined.

These dates describe private product milestones. They are not backdated GitHub contributions, and the first public commits use their actual publication time.

## Public release policy

- Public commits use current author and committer timestamps.
- Source is published in reviewable functional slices.
- Hosted-only services and secrets are removed before publication.
- Material changes include validation or tests where applicable.
- The `gardnsolana` account publishes and maintains this public mirror.
